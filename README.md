# Basic Calculator in C

A simple command-line calculator written in C that performs basic arithmetic operations.

## Features
- Menu-driven interface
- Addition, subtraction, multiplication, division
- Handles division by zero
- Input validation for invalid menu choices

## Tech Stack
- Language: C
- Compiler: GCC (MinGW-w64)

## How to Compile and Run

1. Make sure GCC is installed.
2. Open a terminal in this folder.
3. Compile: "gcc main.c -o calculator.exe"
4. Run: ".\calculator.exe"
